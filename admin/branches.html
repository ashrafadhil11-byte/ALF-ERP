Reference rule

D B C 000001
  • D destination — the number below, or the country's 2-letter code if it isn't listed
  • B branch AWB digit (set per branch)
  • C cargo type code
  • 000001 runs per branch + destination and never resets. All 2-letter countries share one series per branch.
Changing a code only affects new bookings. Removing a country makes it use its 2-letter code (shared series).
